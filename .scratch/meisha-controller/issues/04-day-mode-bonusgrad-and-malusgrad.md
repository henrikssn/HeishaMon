# 04: Space Heating Start (`Day Mode #1`) and Flow Temperature Modulation (`Bonusgrad` & `Malusgrad`)

**What to build:** Implement daily space-heating startup (`Day Mode #1`) at `heating_start_hour:00` and continuous flow-temperature modulation (**Bonusgrad** curve ramp, **Malusgrad** ramp-down, and **Bonusgrad** high-temperature anti-overshoot protection) with **Change Lock** enforcement and non-blocking command sequencing, operating in both **Shadow Mode** and `Active` mode.

**Blocked by:** 03: Heating Day Reset, Curve Target, I-Only PID, Power Target, and Degree-Hour Budget

**Status:** ready-for-agent

- [ ] `Day Mode #1` at `heating_start_hour:00` (when `cooling_mode == off`): after resetting daily accumulators and waiting 10 seconds non-blockingly, if `hours_time_left > 1.0`, ensures operating mode is `Heat only` (unless `valve == Tank` or mode is `DHW only`), turns the heat pump on, and if `int(heat_pump_setpoint) < max(27, power_target)` sets **Heat Pump Setpoint** (`SetZ1HeatRequestTemperature`) to `max(27, power_target)`.
- [ ] **Bonusgrad** curve ramping (when `cooling_mode == off`, `valve == Room` continuously for `>= 10 min`, `compressor_running == on` continuously for `>= 5 min`, `int(main_outlet_temp) + 1 > main_target_temp`, `degree_hours_day * 1.05 < degree_hours_target`, `int(heat_pump_setpoint) < power_target`, and `now >= change_lock`) sets **Heat Pump Setpoint** to `max(int(heat_pump_setpoint) + 1, int(z1_temp) + 1)` and sets `change_lock = now + 30 min`.
- [ ] **Malusgrad** ramping (when `cooling_mode == off`, `valve == Room` continuously for `>= 10 min`, `compressor_running == on` continuously for `>= 5 min`, `int(main_outlet_temp) - 1 < main_target_temp`, `main_target_temp > power_target`, `int(heat_pump_setpoint) > power_target`, and `now >= change_lock`) sets **Heat Pump Setpoint** to `max(min(int(heat_pump_setpoint) - 1, int(z1_temp) - 1), power_target)` and sets `change_lock = now + 20 min`.
- [ ] **Bonusgrad** high-temperature anti-overshoot protection (when `cooling_mode == off`, `valve == Room`, `compressor_running == on`, `degree_hours_day < degree_hours_target`, and `z1_temp >= int(heat_pump_setpoint) + 3` held for `1 min`, and a second time if still `>= int(heat_pump_setpoint) + 3` for another `1 min` matching the 1m/2m trigger pair) bypasses `change_lock`, increments **Heat Pump Setpoint** by `+1 K`, and sets `change_lock = now + 15 min`.
- [ ] `change_lock_remaining_min` and `last_action_reason` are published via MQTT Auto-Discovery, and host C++ tests verify `Day Mode #1`, **Bonusgrad**, **Malusgrad**, anti-overshoot, **Change Lock** gating, and **Shadow Mode** vs. `Active` mode command emission.
